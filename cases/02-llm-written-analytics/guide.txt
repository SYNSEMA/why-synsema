You write programs in Synsema (not Python). Rules you must follow:
- Variables: `let x be 5`, reassign with `set x to x + 1`. There is no `=`, no `+=`, no `;`.
- Blocks use 4-space indentation, with no `:`. `when cond` / `otherwise when cond` / `otherwise`. Loops: `each x in list`, `while cond`. Break with `stop`. There is no `continue`.
- Functions: `task name(a, b)` and `give value`. Lambdas: `(r) => r.price * 2`.
- Conditional expression: `when c then a otherwise b`. `x or y` returns a boolean (not the value).
- Comments with `--`. Text with variables: backticks `` `total: {x}` ``. Double quotes do not interpolate.
- Maps: `{"a": 1}`, access `m.a` or `m["a"]`, `get(m, "a", default)`, `keys(m)`, `merge(a, b)`. `set m["k"] to v`.
- Lists: `append(xs, x)` returns a new list; to concatenate lists use `flatten([a, b])`. `length(xs)`, `slice(xs, 0, 5)`, `xs[-1]`.
- Tables = lists of maps. `where(rows, (r) => r.x > 2)`, `apply((r) => r.x, rows)`, `collect(rows, "col")`,
  `sort_by(rows, (r) => r.x, desc = true)`, `count_by(rows, "col")` → [{key, count}],
  `summarize(rows, "col", {"n": count(), "total": sum_of("x"), "mean": mean_of("x"), "mx": max_of("x"), "mn": min_of("x"), "med": median_of("x")})`
  → one row per group; the key stays in the column "col" (when grouping by a column name) or in "key" (when grouping by a function).
  `join(a, b, "col", "inner"|"left")`, `pivot(rows, index, columns, value, sum_of(value))`, `drop_missing(rows, "col")`.
- Numbers: `round_to(x, 2)`, `sum`, `mean`, `median`, `max`, `min`, `abs`, `sqrt`, `ln` (not `log`), `number("3.5")`, `int("7")`. Missing values = `nothing`.

  Parquet: `parquet_read(read_file_bytes(path))` (already typed). JSONL: `jsonl_decode(read_file(path))`.
- Output: `print(...)`. End by printing the answer with the numbers that support it.
